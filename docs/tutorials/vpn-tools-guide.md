# VPN / 代理工具科普：Tailscale、WireGuard、V2Ray、Clash、EasyConnect、Shadowsocks

> 写于 2026-10-18。
> 适合：听说过这些名字、但分不清它们各自干嘛的人；想自己搭一条稳定线路、又不想被概念绕晕的人。

网上教程里这些名字经常混着出现："用 Clash 配 V2Ray 节点"、"公司让装 EasyConnect"、"Tailscale 组个内网"……
其实它们分属三类完全不同的东西：**翻墙代理**（出网）、**组网 VPN**（连自己的设备）、**企业远程办公**（连公司的内网）。
先分清类别，再看原理，就不乱了。

---

## 零、先建立一张地图

| 类别 | 解决的问题 | 代表工具 |
|---|---|---|
| 翻墙代理 | 从国内访问境外网站 | Shadowsocks、V2Ray |
| 代理客户端（规则引擎） | 管理多个代理节点、按规则分流 | Clash |
| 自建 VPN 协议 | 加密隧道，连自己的服务器 | WireGuard |
| 零配置组网 | 把多台设备连成一个虚拟局域网 | Tailscale（基于 WireGuard） |
| 企业 SSL VPN | 远程办公访问公司内网 | EasyConnect（深信服） |

一句话区分 **VPN 和代理**：VPN 是在网络层建一条加密隧道，整台设备的流量都能走进去；
代理是在应用层转发流量，一般只接管你指定的应用或按规则分流。翻墙大多用代理，组网大多用 VPN。

---

## 一、Shadowsocks：轻量翻墙代理的开山鼻祖

- **是什么**：一个轻量级的加密代理协议，2012 年由 clowwindy 开源。注意它只是一个**协议**，
  需要自己有境外服务器来跑服务端。
- **原理**：本机开一个 SOCKS5 端口，应用的流量进来后，用 AEAD 加密算法（如 aes-256-gcm）整体加密，
  发到境外服务器解密后再转发到目标网站。对审查者来说，看到的只是一堆"看不懂"的加密流量。
  后来加上了 simple-obfs / v2ray-plugin 做流量混淆，让加密流量"长得像"普通 HTTPS。
- **适合场景**：个人翻墙入门。延迟低、省电、手机端体验好；服务端配置简单，一条命令就能跑起来。
- **弱点**：协议特征相对固定，深度包检测（DPI）下容易被识别和封锁。只靠"看不懂"混，
  混淆手段是外挂的，不是协议原生能力。

## 二、V2Ray：模块化的代理平台（VMess / VLESS）

- **是什么**：Project V 旗下的代理软件，一个**平台**而非单一协议，支持 VMess、VLESS、Trojan、
  Shadowsocks 等多种协议，可插拔组合。现在常说的"V2Ray 节点"，一般指 VMess 或 VLESS 协议。
- **原理**：核心思路是"伪装"。流量可以走 TCP、WebSocket、mKCP、gRPC 等多种**传输方式**，
  外面再套一层 TLS，看起来就像在访问一个普通 HTTPS 网站。
  进阶形态 **VLESS + Reality** 更进一步：直接"借用"一个真实网站（如微软、苹果官网）的 TLS 指纹，
  审查者看到的就是一次对真实大网站的正常访问，几乎无法区分——这也是目前对抗 DPI 的主力方案。
  （我自己的主力线路就是 VLESS + Reality，之前 WireGuard 被 DPI 掐过两次握手后切过来的。）
- **适合场景**：对稳定性要求高的主力翻墙线路；愿意折腾配置、想要"一次配好长期用"的人。
- **弱点**：概念多、配置复杂，新手容易被传输方式、流控、指纹这些名词淹没。

## 三、Clash：不是协议，是规则引擎

- **是什么**：开源的代理**客户端**（核心已改名 Mihomo，但大家还习惯叫 Clash）。它自己不提供翻墙能力，
  只负责管理和调度：把 Shadowsocks、V2Ray、Trojan 等各种节点接进来，按规则决定流量走哪个节点。
- **原理**：通过 TUN 模式接管系统全部流量（或系统代理模式接管浏览器流量），然后按规则分流：
  国内网站直连、国外网站走代理、广告域名直接拦截。规则文件（yaml）是灵魂，
  一套好规则能做到"无感上网"，不用手动开关代理。
- **适合场景**：手里有多个节点或机场订阅的人；想要"国内外自动分流"的人。
  典型搭配：Clash（客户端）+ V2Ray/Shadowsocks 节点（线路）+ 订阅转换（规则）。
- **注意**：新手最容易混淆的就是它——"Clash 连不上"通常不是 Clash 的问题，
  而是底下的节点失效或规则写错了。

## 四、WireGuard：极简现代的 VPN 协议

- **是什么**：2016 年出现的开源 VPN 协议，代码只有约 4000 行（对比 OpenVPN/IPsec 动辄几十万行），
  已合入 Linux 内核。注意它是**协议**，不是翻墙工具——连谁、去哪，取决于你自己的服务器。
- **原理**：基于 UDP，用 Noise 协议框架做握手，加密（ChaCha20）和认证一次完成，
  没有传统 VPN 冗长的协商过程。两个杀手特性：一是**漫游**——手机从 Wi-Fi 切到 4G，
  IP 变了隧道不断；二是**内核态运行**——速度快、延迟低、省电。
  它的阿喀琉斯之踵是握手包特征固定：DPI 可以识别出"这是 WireGuard 握手"并直接掐掉，
  我的美国 VPS 线路就被这样掐过两次 UDP 握手。
- **适合场景**：自建服务器组网；远程访问家里或公司的内网服务；需要一条"专线"级别的稳定加密隧道。
  我的 Claude 专线就是 WireGuard，只让 Claude 相关 IP 走隧道（分流模式），其他流量不动。
- **弱点**：本身不做伪装，在强对抗网络环境下握手容易被识别；需要至少一台有公网 IP 的服务器。

## 五、Tailscale：基于 WireGuard 的零配置组网

- **是什么**：一家公司提供的组网**服务**，底层数据传输就是 WireGuard，
  但把最麻烦的部分（密钥分发、NAT 打洞、IP 分配）全部托管了。个人版免费，100 台设备以内够用。
- **原理**：控制面是 Tailscale 的中央服务器：你用 Google/GitHub 等账号登录，
  它给每台设备发密钥、分配一个 `100.x.x.x` 的虚拟 IP、协调 NAT 打洞。
  数据面是设备之间直接打洞建 WireGuard 直连；打不通（比如对称 NAT）就走它的 DERP 中继服务器兜底——
  慢一点，但一定能通。流量本身端到端加密，中继服务器也看不到内容。
- **适合场景**：多台设备异地组网。典型用法：家里的 NAS、办公室电脑、云服务器、手机都装上 Tailscale，
  它们就像在同一个局域网里，直接用虚拟 IP 互访：远程桌面、SSH、访问家里跑的服务，一行命令都不用配。
- **弱点**：依赖它的中央控制面（登录、打洞协调要连它的服务器）；免费版有设备数限制；
  中继兜底时速度看运气。

## 六、EasyConnect：深信服的企业 SSL VPN

- **是什么**：深信服（Sangfor）的企业级远程办公方案，国内很多公司用它让员工在家访问内网。
  注意它是**商业闭源软件**，公司 IT 统一部署，个人装不上也用不上。
- **原理**：基于 SSL/TLS 建加密隧道，把你"逻辑上"接入公司内网；特色是**终端安全检查**：
  登录前会检查你的电脑有没有装杀毒软件、系统补丁齐不齐、有没有装违规软件，不合规就不让进。
  还支持应用级发布：只给你开 OA、ERP 等几个应用，而不是整个内网。
- **适合场景**：公司远程办公、居家访问内网系统。就这一种场景，别无其他。
- **注意**：客户端权限很大、常驻后台，会扫描本机安全状态。建议只装在工作电脑上，
  不要为了图方便装在个人主力机上；离职后记得卸载。

## 七、怎么选：三问定位法

1. **你想访问境外网站？** → 选翻墙代理：Shadowsocks 入门，V2Ray（VLESS+Reality）做主力；
   节点多了就用 Clash 统一管理、自动分流。
2. **你想把自己的几台设备连成内网？** → 别折腾翻墙工具，直接上 Tailscale，十分钟搞定；
   有公网服务器、想完全自主可控，再考虑裸 WireGuard 自建。
3. **公司让你装 EasyConnect？** → 照做，但只装在工作机上；它和翻墙是两回事，
   不要指望它帮你上外网（公司的出口策略说了算）。

| 工具 | 本质 | 要不要自己的服务器 | 上手难度 |
|---|---|---|---|
| Shadowsocks | 代理协议 | 要（境外 VPS） | 低 |
| V2Ray | 代理平台 | 要（境外 VPS） | 中高 |
| Clash | 代理客户端/规则引擎 | 不要（用现成节点） | 中 |
| WireGuard | VPN 协议 | 要（任意 VPS） | 中 |
| Tailscale | 组网服务 | 不要 | 低 |
| EasyConnect | 企业 VPN | 公司提供 | 低（按 IT 指引装） |

## 八、几句提醒

- **免费节点和来路不明的"机场"**：流量经过别人的服务器，账号密码都有被嗅探的风险。
  能自己搭就自己搭，嫌麻烦就选口碑好的付费服务，别贪免费。
- **公司数据走公司通道**：用 EasyConnect 处理工作时，遵守公司的数据安全规定；
  不要把翻墙代理和公司内网混在一条线路上。
- **工具会过时，原理不会**：DPI 和伪装是持续的攻防。今天 VLESS+Reality 好用，
  不代表永远好用。理解"加密-伪装-分流"这三层，比记住某个具体配置长寿得多。
